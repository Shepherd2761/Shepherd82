How to Create a QR Code for a Link or Text

A QR code is a machine-readable pattern that can store information such as a website address or short text. A phone camera or QR scanner can decode the pattern and open or display the stored information.

Common QR code uses

  • Website links
  • Menus and product information
  • Contact or event details
  • Short messages
  • Printed marketing materials

How to create one

Open the free QR Code Generator, enter the text or URL, and generate the code. For a website QR code, use the complete address beginning with https:// when appropriate.

Test before printing

Always scan a generated QR code with a phone before distributing it. Check that the destination is correct and that the code is large and clear enough for the expected scanning distance.

Static versus dynamic QR codes

A static QR code contains the encoded information directly. A dynamic QR system can redirect through a service so that the destination can sometimes be changed later. The generator you use determines which type you receive.

Privacy reminder

Do not enter confidential information into a QR generator unless you understand how that service processes the data. Check the relevant tool's privacy note before encoding sensitive content.

FAQ

Can a QR code store a URL?

Yes. URLs are one of the most common uses for QR codes.
