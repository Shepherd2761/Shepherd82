How to Convert Pixels to REM in CSS

px to rem converter, rem to px calculator

The basic idea

CSS pixels and rem units are both used to size web layouts, but rem is relative to the root element's font size. To convert pixels to rem, divide the pixel value by the root font size. To convert rem to pixels, multiply by that font size.

Example and common mistakes

With the common 16px root size, 24px equals 1.5rem and 2rem equals 32px. If a project changes its root font size, the pixel equivalent changes too. Check the actual CSS root setting instead of assuming it is always 16px.
