# ToolNest — Free Browser Tools

Free, privacy-friendly online utilities. No signup and no server required for the core tools.

## MVP
- Age Calculator
- Percentage Calculator
- Date Difference Calculator
- Time Duration Calculator
- Word Counter
- Character Counter
- Image Resizer
- Image Compressor
- QR Code Generator
- WiFi QR Code Generator

Built with plain HTML, CSS and JavaScript for GitHub Pages.

## Deployment
Enable GitHub Pages for the `master` branch with the root folder as the source.
