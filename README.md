# ToolNest — Free Online Tools

**ToolNest** is a free collection of simple browser-based utilities for calculators, text, images and QR codes.

🌐 **Live website:** https://shepherd2761.github.io/Shepherd82/

## Free tools

### Calculators
- [Age Calculator](https://shepherd2761.github.io/Shepherd82/age-calculator/)
- [Percentage Calculator](https://shepherd2761.github.io/Shepherd82/percentage-calculator/)
- [Date Difference Calculator](https://shepherd2761.github.io/Shepherd82/date-difference-calculator/)
- [Time Duration Calculator](https://shepherd2761.github.io/Shepherd82/time-duration-calculator/)

### Text tools
- [Word Counter](https://shepherd2761.github.io/Shepherd82/word-counter/)
- [Character Counter](https://shepherd2761.github.io/Shepherd82/character-counter/)

### Image tools
- [Image Resizer](https://shepherd2761.github.io/Shepherd82/image-resizer/)
- [Image Compressor](https://shepherd2761.github.io/Shepherd82/image-compressor/)

### QR tools
- [QR Code Generator](https://shepherd2761.github.io/Shepherd82/qr-code-generator/)
- [WiFi QR Code Generator](https://shepherd2761.github.io/Shepherd82/wifi-qr-generator/)

## Why ToolNest?

- Free to use
- No signup required
- Fast and simple interface
- Browser-based processing for supported image tools
- Useful calculators and everyday utilities
- Mobile-friendly pages
- Open-source static website hosted on GitHub Pages

## Technology

Built with plain HTML, CSS and JavaScript. No server or database is required for the core tools.
